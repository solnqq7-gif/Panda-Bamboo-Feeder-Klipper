# Panda Bamboo Feeder 自製韌體 安裝說明

適用韌體：v0.10.0
適合：**單色的 Klipper 印表機**。喂竹器只當耗材緩衝器，加上進料、退料時的輔助推送，
**不用原廠 5通**：出料口直接用鐵氟龍管接到印表機。

安裝好之後的日常操作看 [`使用說明.md`](使用說明.md)。

---

## 1. 需要準備的東西

### 硬體

| 項目 | 說明 |
|---|---|
| Panda Bamboo Feeder 本體 | 原廠韌體版本不拘，燒錄會整個換掉 |
| 原廠 24V 變壓器 | 馬達要 24V。只插 USB 的話馬達不會動，螢幕顯示 `NO 24V`。燒錄時可以不接 |
| USB-C 傳輸線 | **要能傳資料**。有些線只能充電，接上後電腦看不到裝置 |
| 電腦 | Windows、macOS、Linux 都可以 |
| 鐵氟龍管（PTFE） | 從喂竹器出料口接到印表機的入料口或擠出機。1.75mm 耗材用外徑 4mm 的管子，接頭照喂竹器原廠說明 |
| 管剪 | 管口要剪平，斜口容易卡料 |
| 2.4GHz WiFi | 喂竹器的晶片（ESP32-S3）**不支援 5GHz** |

### 軟體

| 項目 | 取得方式 |
|---|---|
| Python 3.10 以上 | python.org 下載。Windows 安裝時勾選「Add Python to PATH」 |
| esptool（燒錄工具） | 命令列執行 `python -m pip install esptool` |
| CH340 USB 驅動 | Windows 10／11、macOS、Linux 通常內建或會自動安裝。接上後看不到序列埠（COM 埠）再去 WCH 官網下載 CH340 驅動 |
| 瀏覽器 | 手機或電腦都可以，用來開喂竹器的網頁 |
| Mobileraker + Mobileraker Companion（選配） | 手機推播：卡料、耗材用完、上料沒到位 |
| VS Code + PlatformIO（選配） | 只有要自己改程式、重新編譯才需要 |

### 韌體檔案

到 GitHub 專案的 **Releases** 頁面下載 v0.10.0 的四個檔案，放在同一個資料夾。燒錄時四個都要：

| 檔案 | 寫入位置 |
|---|---|
| `bootloader.bin` | 0x0 |
| `partitions.bin` | 0x8000 |
| `boot_app0.bin` | 0xe000 |
| `firmware.bin` | 0x10000 |

`SHA256SUMS.txt` 可以用來確認檔案沒有損壞。

## 2. 印表機端要有什麼（檢查清單）

### 必要

- [ ] 印表機跑 **Klipper + Moonraker**。有 Mainsail、Fluidd，或 Creality K1 系列 root 之後都有。
- [ ] 喂竹器和印表機在**同一個網路**。
- [ ] Moonraker 允許喂竹器連線，兩種方式擇一（見第 7 節）：
  - 喂竹器的 IP 在 `moonraker.conf` 的 `[authorization] trusted_clients` 範圍內。
    KIAUH、MainsailOS 的預設設定已經包含 `192.168.0.0/16`、`10.0.0.0/8` 等家用網段，**大多數人不用改**。
  - 或是在喂竹器網頁填 Moonraker 的 API key。
- [ ] 耗材路徑是 喂竹器出料口 → 鐵氟龍管 → 印表機。**不經過 5通**。
- [ ] 擠出機能夾住耗材。緩衝要靠兩端都被固定才會作用：一端是喂竹器的齒輪，另一端是印表機的擠出機。

### 建議

| 項目 | 用在哪裡 | 沒有的話 |
|---|---|---|
| 一顆 `[filament_switch_sensor]`，最好在擠出機附近 | 進料送到擠出機自動停、自動量路徑長度、擠出機空了就不輔助進料、安裝測試前的檢查 | 還是能用，進料只照設定的距離送 |
| `[pause_resume]` 和 `PAUSE` 巨集 | 卡料時自動暫停列印 | 卡料時只會推播 |
| `[display_status]` | 退料 G-code 用 `M117 PBF:FREE`／`PBF:FOLLOW` 跟喂竹器交握 | 改用 `[gcode_macro PBF]` 備用管道，或只靠回抽長度判斷 |
| 印表機自己的斷料處理（斷料感測器 + `pause_on_runout` 或 `runout_gcode`） | 耗材用完時由印表機暫停 | 喂竹器在料用完時**只推播，不會暫停印表機**。管子裡剩的料印完就會空印 |

`[pause_resume]` 和 `[display_status]`：Mainsail 的 `mainsail.cfg`、Fluidd 的 `client.cfg` 都已經內建。

感測器只支援開關式的 `filament_switch_sensor`。編碼器式的 `filament_motion_sensor` 開機後在料動之前
都回報「無料」，會讓喂竹器以為擠出機是空的，所以不會出現在選單裡。

### Klipper 內建、不用另外設定

`print_stats`、`motion_report`、`extruder`、`SET_STEPPER_ENABLE`、`M104`、`M83`、`G1`、`M400`
（安裝測試會用到後面幾個）。

## 3. 先備份原廠韌體（強烈建議）

備份整顆 16MB flash，以後想回到原廠（含原本所有設定）就寫回去。

1. 用 USB-C 接上喂竹器和電腦。
2. 找序列埠名稱：
   - Windows：裝置管理員 →「連接埠 (COM 和 LPT)」→ `USB-SERIAL CH340 (COM5)` 之類
   - macOS：`/dev/cu.wchusbserial…` 或 `/dev/cu.usbserial-…`
   - Linux：`/dev/ttyUSB0`
3. 執行（把 `COM5` 換成你的埠）：

```bash
python -m esptool --chip esp32s3 --port COM5 --baud 921600 read-flash 0 0x1000000 pbf_backup.bin
```

大約 3～4 分鐘。把 `pbf_backup.bin` 存到安全的地方。

---

## 4. 燒錄韌體

在放那四個檔案的資料夾裡開命令列，執行（把 `COM5` 換成你的埠）：

```bash
python -m esptool --chip esp32s3 --port COM5 --baud 921600 write-flash 0x0 bootloader.bin 0x8000 partitions.bin 0xe000 boot_app0.bin 0x10000 firmware.bin
```

- esptool 4.x 版的指令是 `write_flash`（底線），其他都一樣。
- 這個指令**不會清掉原廠存的 WiFi 和印表機位址**，新韌體第一次開機會自動沿用。
- 出現 `Failed to connect`：換一條 USB 線或換一個 USB 孔，並關掉其他正在用這個序列埠的程式（切片軟體、序列埠監看工具）。
- 用 USB 更新時一律寫這四個檔。只寫 `firmware.bin` 的話，如果之前用網頁更新過，開機可能還是跑舊版。

寫完會自動重新開機，螢幕顯示狀態就是成功了。

---

## 5. 連上 WiFi

- **從原廠韌體燒過來的**：自動沿用原廠存的 WiFi，不用設定。
- **沒有設定過，或 20 秒內連不上**：喂竹器會自己開熱點
  1. 手機連 WiFi **`PBF-xxxx`**，密碼 **`pbf12345`**
  2. 瀏覽器開 **http://192.168.4.1**
  3. 在網頁最下面的「WiFi」填名稱和密碼，按「儲存並重新開機」

連上之後，螢幕第三行會顯示喂竹器的 IP。之後用 `http://<那個 IP>` 或 `http://pbf.local` 開網頁
（部分 Android 手機不支援 `.local`，請用 IP）。

網頁沒有密碼保護，同一個網路內的人都能開。

## 6. 設定印表機連線

網頁「設定」→「印表機連線」：

| 欄位 | 填什麼 |
|---|---|
| 啟用 | 勾選 |
| 印表機名稱 | 你的印表機叫什麼，例如 `Voron`、`K1`。網頁、螢幕、推播都會用這個名字。英數，最多 12 字 |
| 位址 | 印表機的 IP，例如 `192.168.1.100` |
| 連接埠 | Moonraker 的埠，一般是 **7125** |
| API key | **先留空**。只有第 7 節那種「被拒絕」的情況才需要 |
| 耗材感測器 | 先用「自動」。儲存後選單會顯示它挑了哪一顆，不對再手動選 |
| 感測器偵測到料後再送 | 感測器到擠出機齒輪的距離，再加約 10mm。感測器裝在料架旁邊的話，就量那段管子的長度（最多 5000mm） |

按「儲存設定」。上方狀態列出現「印表機名稱：閒置」就是連上了。

## 7. 連線被拒絕（Moonraker 登入）

狀態列顯示 **「被拒絕（要 API key）」**，記錄會寫 `Moonraker refused the feeder (HTTP 401)`，
代表 Moonraker 不信任喂竹器的 IP。兩種解法，擇一：

**方法 A：把喂竹器加進信任清單**（改印表機設定）

在 `moonraker.conf` 的 `[authorization]` 區段，`trusted_clients` 加上喂竹器的 IP 或整個網段：

```ini
[authorization]
trusted_clients:
    192.168.0.0/16
```

存檔後重新啟動 Moonraker。

**方法 B：在喂竹器填 API key**（不改印表機設定）

1. 取得 Moonraker 的 API key：用 SSH 登入印表機主機，執行 `~/moonraker/scripts/fetch-apikey.sh`。
   如果你的電腦本身是 Moonraker 信任的，也可以直接用瀏覽器開 `http://<印表機 IP>:7125/access/api_key`。
2. 貼到喂竹器網頁「API key」欄位，儲存。

注意：

- **key 填錯反而會連不上**：Moonraker 看到錯的 key 會直接拒絕，就算這個 IP 本來是信任的也一樣。
  原本就連得上的話，這一欄請留空。
- 網頁不會顯示已存的 key，只顯示「已設定」。欄位留空按儲存＝不變；要刪掉請按「清除 API key」。

## 8. 裝耗材、第一次上料

1. 鐵氟龍管一端接喂竹器出料口，另一端接印表機的入料口（或擠出機）。
2. **第一次上料前**，把網頁「操作」的**距離進料**設成比整段管長再多約 100mm。有感測器的話，
   它會在感測器觸發時自動停下，並把實際量到的長度存起來；距離太短的話，料還沒到感測器就停了，會報錯。
3. 把耗材插進入料口：喂竹器會自己咬料、預載 100mm，停在 **STAGED**。
4. 按一下**上鍵**：把料送到印表機，停下後變成 **READY**（緩衝啟動）。
5. 在印表機上進料（加熱、擠出），讓擠出機夾住耗材。可以用 [`tip-forming-generic.md`](tip-forming-generic.md)
   的進料範本，讓喂竹器同步推料。

---

## 9. 安裝測試（第一次一定要跑）

預設的電流和停駐量是在 K1 上量出來的，換一台印表機、換一種管長都要重新量。

**開始前**：耗材已經被印表機的擠出機夾住（有感測器的話要顯示有料）、印表機沒在列印、喂竹器在 READY 或 STAGED。

網頁「安裝測試」→ 按 **綜合測試**：

1. 緩衝量測試：把活動件推到底，量行程，設定停駐量。約 20 秒，不花耗材。
2. 壓力測試：找出最低夠用的推料電流和夾持電流。**會把噴頭加熱到「壓力測試噴頭溫度」**（預設 230°C，
   PLA 可以先改成 210 左右），用掉約 30cm 耗材，約 4～8 分鐘。

結果自動存進設定。測試中按喂竹器任一鍵，或再按一次同一個按鈕就會中止。

---

## 10. 退料 G-code（選配，建議）

退料時讓喂竹器放開齒輪、再同步收料，要在退料 G-code 裡加幾行 `M117`。
範本和說明：

- 一般 Klipper 印表機：[`tip-forming-generic.md`](tip-forming-generic.md)
- Creality K1 Max：[`tip-forming.md`](tip-forming.md)

不加也能用：非列印中回抽累計超過 25mm，喂竹器會自動改成放開齒輪。

---

## 11. 之後更新韌體

- **網頁更新**（最方便）：網頁「韌體更新」選 `firmware.bin` 上傳，完成後自動重開機。**不要在列印中更新**。
- **USB 更新**：照第 4 節，四個檔一起寫。

更新版本時統計會歸零，設定會保留。

---

## 12. 還原原廠

用第 3 節的備份：

```bash
python -m esptool --chip esp32s3 --port COM5 --baud 921600 write-flash 0 pbf_backup.bin
```

沒有備份的話，用 BIQU 官方提供的原廠韌體檔案，依官方說明燒錄。

## 13. 疑難排解

| 狀況 | 原因 | 處理 |
|---|---|---|
| 電腦看不到序列埠 | 線只能充電，或缺驅動 | 換傳輸線；安裝 CH340 驅動 |
| `Failed to connect` | 序列埠被其他程式佔用，或接觸不良 | 關掉其他程式、換 USB 孔 |
| 螢幕顯示 `NO 24V` | 沒接 24V 變壓器 | 接上變壓器 |
| 狀態列「未連線」 | 位址或連接埠錯、不同網路 | 確認 IP；Moonraker 一般是 7125；電腦瀏覽器開 `http://<IP>:7125/server/info` 看有沒有回應 |
| 狀態列「被拒絕（要 API key）」 | Moonraker 不信任喂竹器 | 見第 7 節 |
| 耗材感測器選單「沒找到感測器」 | 印表機沒有 `filament_switch_sensor` | 沒關係，進料照距離送；或在印表機加一顆 |
| 進料報錯「never saw the filament」 | 距離進料比到感測器的路徑短，或料卡在半路 | 把距離進料加長；檢查管路 |
| 列印中緩衝不動作、一直 STUCK | 擠出機沒夾住料，或「空閒時放鬆馬達」被打開 | 先讓印表機進料；關掉「空閒時放鬆馬達」；跑綜合測試 |
| 退料 G-code 報 `Unknown command: M117` | 印表機沒有 `[display_status]` | 見 [`tip-forming-generic.md`](tip-forming-generic.md) 第 6 節 |
| 沒收到推播 | 沒裝 Mobileraker Companion | 安裝 Companion；網頁有「測試推播」按鈕 |
