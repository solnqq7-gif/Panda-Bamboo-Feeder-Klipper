# 退料尖端成形（tip forming）—— K1 Max 版

對象：Creality K1 Max（擠出機有改過，要比原廠多退約 10mm）+ Panda Bamboo Feeder 自製韌體 v0.8.8 以上。
其他 Klipper 印表機請看通用版 [`tip-forming-generic.md`](tip-forming-generic.md)：同樣示範 `M117 PBF:FREE`／`PBF:FOLLOW` 的用法，
但不用 K1 才有的 `RESTORE_E_CURRENT`／`SET_E_MIN_CURRENT`。

前提：
- **不做 250mm 長抽**。K1 只把料頭退到離開自己的擠出機齒輪，剩下的按 PBF 退料鍵拉回料盒。
- **Mobileraker 執行前會先加熱到 230 °C**，所以 G-code 不寫 `M109`。
- **印表機的 `printer.cfg` 不改**，所有東西都在 Mobileraker 的 G-code 和 PBF 韌體裡。
- **目標是料頭不卡住**。帶一點細絲可以接受。

## 1. 目前版本：原廠成形序列 + FOLLOW 收尾（2026-09-24）

尖端成形的部分**跟原廠 `_UNLOAD_FILAMENT` 一模一樣**。成形期間喂竹器放開齒輪（FREE），
成形做完改成主動同步收料（FOLLOW），把料頭拉離擠出機齒輪。

```gcode
RESTORE_E_CURRENT
M117 PBF:FREE
G4 P400
M83
G1 E10 F300
G1 E-15 F3000
G1 E-22.4700 F2400
G1 E-6.4200 F1200
G1 E-3.2100 F720
G1 E5.0000 F356
G1 E-5.0000 F384
G1 E5.0000 F412
G1 E-5.0000 F440
G1 E5.0000 F467
G1 E-5.0000 F495
G1 E5.0000 F523
G1 E-5.0000 F3000
G1 E-15 F3000
M400
M117 PBF:FOLLOW
G4 P400
G1 E-60 F2000
M400
M117
SET_E_MIN_CURRENT
```

### 和原廠的差異（只有這幾處）

| 位置 | 原廠 | 這版 | 為什麼 |
|---|---|---|---|
| 開頭 | `M109 S{hotend_temp}` | 拿掉 | Mobileraker 已經加熱到 230 才讓你執行 |
| 開頭 | — | `M117 PBF:FREE` + `G4 P400` | 成形期間叫喂竹器放開齒輪，等兩個輪詢週期 |
| 成形後 | — | `M400` + `M117 PBF:FOLLOW` + `G4 P400` | 成形真的做完才切換；喂竹器夾回來，準備同步收料 |
| 結尾 | — | `G1 E-60 F2000` | 把料頭從 62mm 拉到 122mm，離開擠出機齒輪和噴頭感測器 |
| 結尾 | — | `M400` + `M117` | 等動作做完，清掉訊息 |

`RESPOND TYPE=command MSG="Unloading filament..."` 那行也拿掉了，只是顯示訊息。
原廠不會關加熱，這版也不關（Klipper 閒置 10 分鐘會自己關）。

### 料頭位置

| 指令 | 料頭離噴嘴 | 喂竹器 |
|---|---|---|
| `G1 E10 F300`（ram） | 0 | FREE |
| `E-15` / `E-22.47` / `E-6.42` / `E-3.21` | 15 → 37.5 → 43.9 → **47.1** | FREE |
| ±5 四組冷卻擺動（約 5 秒） | 42.1 ↔ 47.1 | FREE |
| `G1 E-15 F3000`（原廠結尾） | 62.1 | FREE |
| `G1 E-60 F2000`（新加，約 1.8 秒） | **122.1** | FOLLOW |

淨 E = −112.1mm，料頭行程 122.1mm。差的 10mm 是 ram 擠出噴嘴外的料，那段不會回來，
**判斷有沒有離開齒輪要看 122，不是 112。**

距離怎麼來的：原廠擠出機料頭行程約 102mm 就離開齒輪；你的擠出機改過要多約 10mm（112）；
再多留 10mm 餘量 → 122。

### 為什麼最後一段改用 FOLLOW（上一版是 FREE + `E-50`）

2026-09-22 到 09-24 用的版本整段都是 FREE，結尾 `G1 E-50 F2000`（料頭 112mm）。改成 FOLLOW 的原因：

- **FREE 時料頭一離開 K1 齒輪就沒人拉了**，會停在齒輪正上方。FOLLOW 時喂竹器繼續同步倒轉，
  把最後 10–20mm 也拉走，料頭確實離開齒輪和噴頭感測器。
- 多了 10mm 餘量（112 → 122）。
- 這段是單向的長回抽，沒有來回擺動，0.2 秒輪詢的 FOLLOW 追得上（2026-09-20 實測跟過 302mm 的 `F2000` 回抽）。

**FOLLOW 只改變料頭停在哪裡，不改料頭形狀。** 形狀完全由前面的原廠成形段決定。

## 2. 不要改成形段

### 2026-09-21：32mm 成形 + skinnydip（實測卡料）

在離噴嘴 32mm 成形、±8mm 擺動到 45mm/s、再 skinnydip（+25mm 沾回熔融區再 70mm/s 抽出）、成形前降溫。

**實測結果：料頭粗到 2.2mm 以上，卡住。** 原廠序列在這台機器上反而沒問題。

最可能的原因（沒有逐項測試，是推測）：

- **32mm 還太靠近熱區**：料在那裡還是軟的，±8 的推回動作把它壓扁。原廠在 42–47mm 擺動，
  那裡已經夠冷，擺動只會拉細不會壓粗。
- **skinnydip 把已經成形的軟料頭往下推 25mm**，直接式沒有冷卻管限制直徑，推下去就變蘑菇。

當初說原廠序列「是 Prusa MK3 參數、在 K1 上沒效果」的判斷，**實測證明是錯的**。

### 2026-09-24：只留一組冷卻擺動、抽離降到 F2000（沒有採用）

考慮過把 4 組 ±5 冷卻擺動砍到只剩最後一組（`E5 F523` / `E-5 F2000`），
並把最後的 `E-5` / `E-15` 從 F3000 降到 F2000。**沒有實測，判斷會更容易出鈍頭，所以沒採用：**

- ram + 回抽 47mm 之後料頭還是軟的。4 組擺動讓它在冷區停留約 5 秒、一邊動一邊硬化
  （動著才不會黏在管壁上）。砍到約 0.7 秒，料頭還軟就被拖過散熱座、齒輪、管口，
  容易變成蘑菇頭或拖出細絲。
- 最後那下 50mm/s 快抽是把已經拉細的頸部乾淨扯斷；降到 33mm/s 比較容易拉出絲。

**這份文件以原廠序列為準。** 要改成形段之前，先用第 4 節的方法量現在這版的料頭。

## 3. 確認料頭有離開擠出機齒輪

112mm 是估的需求（K1 噴嘴到齒輪約 45–50mm + 噴頭感測器 + 改機多出的 10mm），122 多留了 10mm。

**驗收測試**：退料完按一下 PBF 的退料鍵。拉得動 = 料頭已經離開 K1 的齒輪；
打滑磨料 = 還被夾著，把 `-60` 加大。
（喂竹器拉不出 K1 擠出機夾住的料，2026-09-20 已經驗證過。）

**也要確認噴頭感測器放開了**：進料開始時感測器如果還是「有料」，喂竹器要等它先變無料、
再變有料才會停，這種情況下次進料就不會在擠出機停下來：

```bash
curl -s "http://192.168.1.100:4409/printer/objects/query?filament_switch_sensor%20filament_sensor_2"
```

`filament_detected` 要是 `false`。

## 4. 料頭實測記錄

要判斷成形好不好，只能量。每次退料後：

1. 按 PBF 退料鍵把耗材拉出來，剪下最前面約 30mm。
2. 用卡尺量**最粗的地方**，拍一張側面照片。
3. 記下形狀：尖／鈍但不粗／蘑菇頭（比線徑粗）／帶細絲（長度大約多少）。
4. 記下有沒有卡住、卡在哪裡：退料時齒輪上方／按退料鍵拉回料盒時／下次進料時。

合格標準：**沒有卡住**，細絲可以接受。最粗處暫定 **≤ 1.9mm**
（原本訂 1.8，但 2026-09-24 量到 1.87 沒卡住；09-21 那版 2.2mm 以上會卡，上限在這兩個數字之間）。

為什麼 1.87 還過得去：料頭最粗那一段，很可能是在熱端內孔（1.75 耗材的熱端一般約 2mm）裡熔化、
被拉上來時定型的，所以它本來就過得了同樣粗的孔。會卡住的是**離開內孔之後又被擠變形**的料頭
（例如 skinnydip 把軟料頭推回去壓成蘑菇頭），那種才會超過 2mm。

| 日期 | 版本 | 耗材／溫度 | 最粗處 (mm) | 形狀 | 細絲 | 卡住？位置 |
|---|---|---|---|---|---|---|
| 2026-09-24 | 原廠成形 + FOLLOW 60 | 黑色 PETG／230 °C | 1.87（距頂端約 4mm，不含細絲） | 短錐形，頸部一小段表面略凹凸發亮，沒有蘑菇頭 | 有，一條長細絲（照片目測約數公分） | 沒有 |
| | 原廠成形 + FOLLOW 60 | | | | | |
| | 原廠成形 + FOLLOW 60 | | | | | |

同一捲料至少跑 3 次再下結論，單次結果差異很大。

### 溫度（Mobileraker 退料前的加熱溫度）

- **PETG：維持 230 °C，不要再降。** 230 已經在 PETG 的下緣，再低的話 ram（`E10 F300`，約 12mm³/s）
  可能推不動。PETG 本來就容易拉絲，料頭帶一條長細絲是材料特性，不是成形序列有問題。
- **PLA：230 °C 偏熱**，可以試 215 °C，細絲通常會短一些。一次只改溫度這一個變數。

## 5. TPU

原廠序列的 `F3000`（50mm/s）回抽對 TPU 不適合：TPU 有彈性，快抽只會把料拉長再彈回，
可能在散熱區屈曲卡死。可以試把所有 `F` 值減半，並把 Mobileraker 的起始溫度
從 210 拉到 230（TPU 在 210 推料阻力大，容易被齒輪咬扁）。**這個沒有實測過。**

## 6. 喂竹器放開齒輪（FREE）和同步收料（FOLLOW）

### 為什麼成形時要放開

原廠序列有 4 組 ±5mm 的快速來回擺動。即使 FOLLOW 現在能雙向同步，它仍靠 0.2 秒一次的輪詢反應，
追不上這種短動作，容易在動作已經換向後才跟上。尖端成形這一段仍應使用 FREE。
放開齒輪讓它空轉，由印表機自己拉，就沒有這個問題。

FREE 期間退回來的料（目前版本料頭走到 62mm）一部分被緩衝活動件吸收，其餘留在管子裡。
**更長的回抽不要在 FREE 裡做**：入料端沒有東西收，幾百 mm 會塞成一團。要退更遠就切 FOLLOW。

### 訊號：`M117 PBF:FREE`

`M117` 會寫進 Klipper 的標準物件 `display_status.message`，喂竹器輪詢時順便讀，
所以印表機端不用加任何設定。

- 訊息含 `PBF:FREE` → 進入 **FREE**，馬達斷電、嗶一聲，齒輪空轉。
- 訊息清掉／改掉、逾時、按任一鍵、K1 開始列印、失去連線 → 夾回來。
- 夾回來時 K1 噴頭已經沒料 → 停在 **STAGED** 並持續夾住，接著按退料鍵就能拉回料盒。
- FREE 一觸發就開始 60 秒保護；即使提早夾回，這段時間也不會自動補料把耗材推回 K1。

喂竹器自己送的推播是 `M117 $MR$:PBF: 卡料|…`，`PBF:` 後面不是 `FREE`，不會誤判。

### 從 FREE 切到 FOLLOW：`M117 PBF:FOLLOW`

目前的退料版本就是這樣用：成形做完切 FOLLOW，讓喂竹器主動同步收最後 60mm。

```gcode
M400              ; 成形真的做完才切換
M117 PBF:FOLLOW
G4 P400           ; 等兩個輪詢週期
G1 E-60 F2000     ; 要退出幾百 mm 的話把距離加大
M400
M117
```

喂竹器的反應順序：

1. 訊息從 `PBF:FREE` 變成 `PBF:FOLLOW` → 算「訊息改掉」，離開 FREE、夾回齒輪。
2. K1 的 E 速度超過 3mm/s → 開始同速倒轉（最快 60mm/s）。
3. K1 停下 → 喂竹器停下。收的量超過 20mm，判定為退料，停在 **STAGED**，不自動補料。

**`M117 PBF:FOLLOW` 前面的 `M400` 不能省**：`M117` 在 G-code 佇列裡會比前面的移動先生效，
少了 `M400`，成形還在擺動喂竹器就夾回來了。

`FREE`／`FOLLOW` 不分大小寫，所以 `M117 PBF:follow` 也有效。明確 FOLLOW 期間不會因累計回抽超過 25mm
又切回 FREE，並會同時跟隨正向進料與反向退料。K1 正式列印中不執行 FOLLOW，避免訊號忘記清除後持續送料。

### 備援：沒有訊號時靠回抽長度判斷

用 K1 觸控螢幕退料（`QUIT_MATERIAL`）不會有 `M117`。所以跟隨回抽累計超過 25mm
（可設）也會改成放開，停止回抽 3 秒後夾回來。用在原廠序列上：`E-15` 之後
`E-22.47` 走到一半就超過門檻。擺動中的空檔最長約 0.85 秒（`E5 F356`），不會被誤判成結束。

這台機器的 `PAUSE` 只退 3mm，一般列印回抽更小，都不會誤觸。
`M600` 會呼叫 `_UNLOAD_FILAMENT`（52mm），會觸發 —— 換料時放開本來就對。

### 安全機制

| 機制 | 行為 |
|---|---|
| 逾時（預設 60 秒，5–600） | 自動夾回，而且在訊息變掉之前不會再放開 |
| 按任一鍵 | 立刻夾回，同樣鎖住 |
| K1 開始列印 / 失去連線 | 立刻夾回 |
| 開機時訊息已經是 `PBF:FREE` | 不動作，要等訊息清掉一次才算數 |
| FREE 後 60 秒補料保護 | 不做自動補料；`PBF:FOLLOW` 仍可同步。K1 開始正式列印時立即取消保護並恢復補料 |

後兩項是因為 `M117` 的訊息會一直留著。退料被取消的話 `PBF:FREE` 會留在畫面上，
沒有這兩個機制的話，齒輪會一直被重新放開 —— 夾不住等於沒裝喂竹器。

### 相關設定（網頁）

| 設定 | 預設 |
|---|---|
| K1 退料時放開齒輪（M117 PBF:FREE） | 開 |
| 放開齒輪逾時 | 60 秒 |
| 沒有訊號時靠回抽長度判斷 | 開 |
| 判定為退料的回抽長度 | 25mm |

手動測試：網頁的「放開齒輪／夾住齒輪」按鈕，或序列埠 `free` / `grip`。

## 7. K1 注意事項

- **`RESTORE_E_CURRENT` 不能省**。K1 待機時擠出機電流很低，少了會打滑。
- **結尾的 `SET_E_MIN_CURRENT` 也不能省**，而且前面要有 `M400`。少了它擠出機馬達閒置時一直維持高電流、發熱。
- 會從噴嘴擠出 10mm 料，執行前先把噴頭移開列印物。
- 不要把巨集命名成 `_UNLOAD_FILAMENT` / `UNLOAD_FILAMENT` / `LOAD_FILAMENT`
  （如果哪天要做成巨集），原廠 cfg 會覆蓋掉。
