# Panda Bamboo Feeder 自製韌體 使用說明

適用韌體：v0.11.9（v0.11.9：網頁新增英文介面，右上角 **English／中文** 切換；這是喂竹器本身的設定，推播通知和設定錯誤訊息也跟著切換。v0.11.8：網頁設定裡比較容易設錯的 15 個欄位旁邊加上圓圈問號，點一下在該欄下方展開說明，再點一次收起。v0.11.7：修正狀態訊息沒更新：噴頭重新加熱、或輔助進料恢復時，`K1 heater off`、`relaxing buffer`、`waiting for K1`、`K1 extruder empty` 這幾行等候訊息會換成 `K1 printing: buffer on`（沒在列印時是 `buffer on`）。之前這行字會沿用到整場列印結束，只是顯示錯誤，送料本來就正常。v0.11.6：**噴頭關加熱時放鬆緩衝**：印表機噴頭目標溫度變成 0 後，活動件靜止 2 秒就慢慢把停駐的那段退回來，活動件一回到原位就停（最多退「停駐量 + 6mm」，不會拉到擠出機裡的料），收尾和閒置時擠出機卡扣不再一直被緩衝拉著；下次加熱時照常輔助進料補回。起因是 2026-10 連續幾次開印頭幾分鐘，管子從擠出機卡扣脫出。省電待機期間也記錄活動件回到／離開原位。v0.11.5：下鍵雙點「退到無料」的上限改成實測退料長度 + 20mm（原本 ×1.3），料頭退過齒輪後一定會再退完 15mm 才停；第 4 節按鍵說明改寫成完整的按鍵行為。v0.11.4：修正手動進退料中雙擊上鍵回 STAGED，停止的第一下也計入雙擊，跟隨動作等當前進退料結束才重新允許。v0.11.3：修正測試結束時干擾列印、雙鍵選單繞過列印保護、開機／斷線誤解除 FREE 鎖定，以及數字設定溢位；加入桌面回歸檢查。v0.11.2：印表機連線斷掉時，沿用最後一次讀到的加熱狀態（K1 印完後常常半分鐘不回應，v0.11.1 在這段時間又往鬆掉的管子推了 82mm）；暫停輔助進料的期間記錄活動件每次回到／離開原位，用來找出管子脫出的時間點；修正兩行記錄同時寫入時會掉一行。v0.11.1：**噴頭沒加熱就不輔助進料**：印表機噴頭目標溫度是 0（收尾巨集已經關加熱，或閒置）時不輔助進料，正在輔助進料也會停下。起因是一次 K1 收尾時管子從擠出機卡扣脫出，喂竹器以為緩衝空了，往鬆掉的管子推了 80mm，還把已經印完的列印暫停。v0.11.0：新增**沒有輔助進料警報**（列印中印表機擠出 100mm 緩衝都沒空過就暫停並推播）；**手工續料**時接頭快到擠出機就持續施壓，直到擠出機把新料吃進去；列印中的輔助進料記錄改成每分鐘一行，記錄不會幾分鐘就被洗掉。v0.10.0：**任何 Klipper 印表機都能用** —— **手工續料**：預載完 3 分鐘內卡料判定放寬成「卡料判定長度 + 路徑長度」，列印中插新料會自動推到舊料尾巴接上；螢幕改版（輔助進料改成標題旁的箭頭動畫、IP 移到 READY 的最下行、`P7` 改寫成 `L7`、IN1／IN2 改成方框圖示）；新增「印表機名稱」（網頁、螢幕、記錄、推播裡原本寫死的「K1」都改成這個名字），耗材感測器改成從印表機的物件清單自動挑選或手動指定（原本寫死 K1 的 `filament_sensor_2`），不再讀 K1 後方的 `filament_sensor`；新增 Moonraker **API key** 欄位（Moonraker 拒絕連線時才需要），連線被拒絕時狀態列顯示「被拒絕」；「感測器偵測到料後再送」上限從 100mm 放寬到 **5000mm**（超過 40mm 的部分用手動送料速度，最後 40mm 慢速），進退料距離上限跟著放寬到 10000mm；退料 G-code 範例分成通用版和 K1 版。v0.9.0：新增**省電待機**（9.6）—— K1 閒置、沒加熱、噴頭冷掉時放開齒輪，K1 一加熱就夾回來；「補料」全部改稱「輔助進料」。v0.8.8：只改網頁 —— 設定分組上底色、進退料電流級別改成下拉選單、統計移到狀態下方並附記錄展開按鈕、「送料／補料速度」改名為「手動送料／輔助進料速度」。v0.8.7：K1 開始列印時立即取消 FREE 輔助進料保護。v0.8.6：`M117 PBF:FOLLOW` 改為進退料雙向同步。v0.8.5：FREE 後 60 秒禁止輔助進料、增加 FOLLOW 訊號、增加進退料距離鎖定）
用途：只當**單色印表機的耗材緩衝器**，並在進料、退料時輔助推送。**不使用 5通**（喂竹器出料口直接用鐵氟龍管接到印表機）。任何 Klipper + Moonraker 的印表機都能用；開發和實測在 Creality K1 Max，本文的例子（IP、G-code）都是這台的。
安裝（需要的工具、燒錄、印表機端檢查清單）：[`安裝說明.md`](安裝說明.md)。

## 1. 連線與網頁

| 項目 | 內容 |
|---|---|
| 網頁 | http://192.168.1.50 或 http://pbf.local（部分 Android 不支援 .local，請用 IP） |
| WiFi | 開機自動連線（第一次沿用原廠韌體存的 WiFi） |
| 連不上 WiFi 時 | 20 秒後自動開熱點 **PBF-xxxx**，密碼 `pbf12345`，網址 http://192.168.4.1 |
| 馬達電源 | 需要接 **24V 變壓器**；只接 USB 時馬達不會動，螢幕顯示 NO 24V |
| 印表機連線 | 自動沿用原廠存的印表機位址（例如 K1 是 192.168.1.100:4409），網頁「設定 → 印表機連線」可修改，名稱也在那裡改。見第 7.5 節 |

網頁沒有密碼保護，同一個網路內的人都能開啟。

## 2. 螢幕

```
READY        ⇨            ← 狀態（大字）；READY 時右邊有輔助進料箭頭
woke: K1 heating          ← 訊息、進度
L7 550mA                  ← 壓力級別、馬達電流（沒有 24V 時顯示 NO 24V）
IN1 ▣ IN2 ▣ BUF:out       ← 感測器：方框中間有實心小方塊 = 有料，空框 = 無料
192.168.1.50 2xUP:STAGED ← READY：IP + 按鍵用途；其他狀態：按鍵用途
```

- **輔助進料箭頭**（v0.10.0）：READY 時標題右邊有一個空心箭頭。輔助進料時箭頭由左往右填滿（依這次預計要送的量），
  補完滿格停 0.3 秒再清空。**輔助進料期間標題維持 READY、訊息列也不變**，畫面不會每補一次料就閃一次（網頁仍會顯示「輔助進料中」）。
- **IP 的位置**：READY 時在最下面一行（原本的 `hold UP:+20` 拿掉了，按住上鍵送料最多 20mm 的功能不變）；
  其他狀態、以及列印中鎖定時，IP 在第三行。
- 第三行的 `L7` 就是網頁的「壓力級別 L7」（v0.9.0 以前螢幕寫成 `P7`，是同一個東西）。

**感測器**

| 螢幕 | 網頁 | 位置與意義 |
|---|---|---|
| IN1 | 入料口 | 入料口旁：有沒有插料；料尾通過時用來判斷斷料 |
| IN2 | 齒輪 | 驅動齒輪旁：料有沒有被齒輪咬住 |
| BUF | 緩衝 | 螢幕 `home`／網頁「原位・空」= 活動件在原位 = **緩衝存料用完，要輔助進料**；螢幕 `out`／網頁「撐開・有存料」= 活動件被多送的料撐離原位 = **緩衝裡有存料**（平常停在行程中間就是這個狀態）。原理見 7.3。v0.8.0 以前螢幕顯示 `rest`／`PULLED`，網頁顯示「靜止」／「被拉出」，是舊的錯誤說法 |

**亮度**

| 情況 | 亮度（預設） |
|---|---|
| 一般（READY 以外的狀態、選單） | 80% |
| READY 待命、STANDBY 省電待機 | 10% |
| READY 下開始輔助進料 | 80%，補完再維持 5 秒 |
| READY 下按任一鍵或在網頁操作 | 80%，維持 10 秒 |

## 3. 狀態一覽

| 螢幕 | 網頁 | 意義 | 緩衝輔助進料 |
|---|---|---|---|
| EMPTY | 無料 | 沒有耗材 | — |
| INSERTING | 咬料中 | 偵測到插料，馬達慢轉讓齒輪咬住 | — |
| PUSH IN | 請把耗材再推進去 | 15 秒內沒咬到料，請再推進去一點 | — |
| PRELOAD | 預載中 | 齒輪咬住後自動送入預載長度（預設 100mm） | — |
| STAGED | 就緒（緩衝暫停，可換管） | 等你送料；**這個狀態不會自動輔助進料**，可以換鐵氟龍管。K1 退料後會自動進入這個狀態 | 暫停 |
| LOADING | 送料中 | 距離進料中，最後 40mm 放慢 | — |
| READY | 待命（緩衝啟動） | 料已經到印表機，印表機吃料時自動輔助進料 | **啟動** |
| FEEDING | 輔助進料中 | 活動件回到原位（緩衝用完了），正在輔助進料 | **啟動** |
| STANDBY | 省電待機（齒輪放開） | READY 時 K1 閒置夠久：馬達斷電不發熱。K1 一加熱、開始列印或按任一鍵就回到 READY，見 9.6 | 暫停 |
| RUNOUT | 斷料：交給 K1 處理 | 料尾已離開齒輪，馬達放鬆，不做任何動作（會推播） | — |
| FOLLOW | 同步 K1 進退料中 | 明確送出 `PBF:FOLLOW` 時雙向同步；沒有標記的自動模式仍只跟回抽 | — |
| FREE | 齒輪放開（印表機自己拉） | 馬達斷電、齒輪空轉，讓 K1 自己把料拉出來（尖端成形／退料用）。見 9.5 | 暫停 |
| UNLOADING | 退料中 | 退料中 | — |
| UNLOADED | 已退料 | 料頭已退過齒輪，可以抽出或重新上料 | — |
| STUCK! | 卡料！ | 輔助進料超過卡料判定長度，活動件還在原位（沒被撐開） | 停止 |
| ERROR | 錯誤 | 見第 8 節 | 停止 |
| NO POWER | 馬達沒有電源 | 沒有 24V | — |

## 4. 實體按鍵

上鍵 = 進料，下鍵 = 退料。

**判定時間**

| 操作 | 判定 |
|---|---|
| 單點 | 按下後 0.6 秒內放開 |
| 按住 | 按住超過 0.6 秒；放開就停 |
| 雙點 | 兩次單點間隔在 0.45 秒內 |
| 兩鍵同時按 | 兩鍵一起按住 1 秒 |

**特殊狀態優先**：喂竹器處在下列狀態時，按鍵先照這張表處理（由上往下判斷），這一下不會再觸發下面「一般操作」的動作。

| 狀態 | 按任一鍵 |
|---|---|
| 設定選單開著 | 交給選單操作（第 5 節） |
| STUCK!／ERROR | **解除警報**，回到一般狀態 |
| FREE（齒輪放開） | 夾回齒輪，結束 FREE |
| STANDBY（省電待機） | **只喚醒**回到 READY（螢幕是暗的，看不到當下的按鍵用途）。網頁上的操作則會喚醒並直接執行 |
| K1 列印中（按鍵鎖定） | 有動作在跑就停止；沒有的話短嗶一聲，螢幕顯示「LOCKED: K1 printing」。K1 暫停時可以正常操作 |
| 有動作在跑（咬料、預載、進退料、FOLLOW 跟隨、測試、按住進退料） | **立即停止**。停止的那一下放開時不算單點（上鍵的例外見下方） |

**一般操作**

| 操作 | STAGED 及其他狀態 | READY／FEEDING（料已在印表機） |
|---|---|---|
| 上鍵單點 | **距離進料**（預設 500mm）；料只在入料口、還沒被咬住時改成咬料；完全沒有料則不動作 | 不動作，螢幕提示 `hold UP to feed (max 20mm)` |
| 上鍵按住 | 按著就持續進料（15mm/s） | 進料，**每次按住最多 20mm**；正在輔助進料會先停下 |
| 上鍵雙點 | 手動進退料中且 IN2 有料時，**停止並回到 STAGED** | **回到 STAGED**（暫停緩衝，可換管） |
| 下鍵單點 | **距離退料**（預設 600mm）；料頭提早退過齒輪，就再退 15mm 停。齒輪沒有料時不動作 | 同左 |
| 下鍵單點後 2 秒內再按下鍵 | 短按＝停止；按住＝距離退料改成按住退料 | 同左 |
| 下鍵按住 | 按著就持續退料（15mm/s） | 同左 |
| 下鍵雙點 | **退到無料**：料頭退過齒輪後再退 15mm 停。上限是**實測退料長度 + 20mm**（第 10 節「退料上限」），退到上限料頭還在齒輪就報 `tip stuck`（第 8 節） | 同左 |
| 兩鍵同時按 1 秒 | 進入設定選單；列印中或暫停中、馬達在轉、測試中不會進入 | 同左 |

- v0.11.4 起，**停止動作的上鍵短按也算雙擊的第一下**；450ms 內再短按上鍵就回到 STAGED。只按一下停止，不會在等待結束後又開始進料。
- 這個雙擊也適用於按住進退料、網頁進退料和 FOLLOW 跟隨。FOLLOW 停止後，要等印表機目前這段進退料結束才重新允許跟隨，避免剛回 STAGED 就又動起來。
- 下鍵單點要等約 0.5 秒確認不是雙點，才會開始退料。
- **列印中斷線也維持鎖定**（v0.8.2 起）：列印中連不到 K1 時，鎖不會打開，螢幕改顯示「LOCKED: K1 offline」。K1 沒有 Wi-Fi 也會繼續印，所以要等 K1 重新連上並回報「沒在列印」才解鎖。K1 真的斷電或當機時，可以用以下方式解鎖：網頁取消勾選「列印中鎖定按鍵與網頁進退料」，或關閉 K1 連線，或把喂竹器重新開機（開機時還不知道 K1 狀態，不會上鎖）。

## 5. 設定選單（兩鍵同時按 1 秒）

v0.11.3 起，印表機列印中或暫停中不能進入設定選單，即使關掉「列印中鎖定」也一樣。若在選單開啟時開始列印，會自動儲存並退出，讓緩衝繼續運作。

操作：**上鍵** = 下一項（最後一項之後回到第一項），**下鍵** = 修改或執行；數值每按一次加一級，超過上限回到最小值。選單裡只認單點，按住沒有作用。選到 Exit 按下鍵、或再按兩鍵 1 秒，就會離開並儲存。

| 項目 | 說明 |
|---|---|
| Pressure | 壓力級別 L1～L10（見第 7 節） |
| Pressure test | 壓力測試（自動找出最低可用電流，見 7.2） |
| Buffer test | 緩衝量測試（量活動件行程、設定停駐量，見 7.3） |
| Full test | 綜合測試（緩衝量 + 壓力，第一次安裝用，見 7.0） |
| Buzzer | 蜂鳴器開／關 |
| Preload | 預載長度，每次 +10mm，0～200 循環 |
| Load length | 距離進料長度，每次 +50mm，50～1500 循環（上料時會自動校準，見第 7 節） |
| Stuck length | 卡料判定長度，每次 +10mm，30～200 循環 |
| Idle release | 空閒時放鬆馬達。**要用緩衝就必須關**（見 7.1）；綜合測試會自動關掉 |
| Brightness | 一般亮度，10～100% |
| Dim (READY) | READY 亮度，0～50% |

## 6. 網頁

**操作區**

| 按鈕 | 說明 |
|---|---|
| 按住進料（綠）／按住退料（橘） | 手指按著才轉（每秒 20mm）。READY 時按住進料最多 20mm |
| 距離進料［ ］mm | 送出旁邊的距離，數字**和上鍵單點共用**，改完自動儲存 |
| 距離退料［ ］mm | 退回旁邊的距離，數字**和下鍵單點共用**，改完自動儲存 |
| 停止／解除警報 | 停止任何動作（包括測試）、解除警報 |
| 放開齒輪／夾住齒輪 | 手動切換 FREE 狀態，見 9.5。一樣吃逾時 |
| 測試蜂鳴器 | 嗶一聲 |

- 按住按鈕時，手機每 0.25 秒送一次訊號；喂竹器 0.6 秒沒收到就自動停止（WiFi 斷線保護）。切到背景或鎖螢幕也會停止。
- 狀態列的「**本次移動**」可以用來量管長：在 STAGED 用按住進料把料送到擠出機，讀這個數字，填到距離進料。

**安裝測試區**：綜合測試、緩衝量測試、壓力測試三個按鈕，見 7.0。

**統計區**（v0.8.8 起在狀態和操作之間）：累計數字見 10.5。紅色「清除統計」會先跳確認；右邊「展開記錄／摺疊記錄」切換即時記錄，預設摺疊，手機會記住上次的選擇。

**其他區塊**：設定（第 10 節）、WiFi 設定、韌體更新（第 11 節）。

## 7. 安裝測試、壓力級別與路徑校準

### 7.0 安裝測試（第一次安裝從這裡開始）

v0.11.3 起，列印中或暫停中不能開始測試。測試中途若印表機開始列印，測試會停止，並保留列印正在使用的噴頭目標溫度與擠出機啟用狀態；正常在閒置時結束測試，仍會恢復原本溫度。

網頁的「安裝測試」區有三個按鈕，螢幕選單也有同樣三項（Full test／Buffer test／Pressure test）。

| 按鈕 | 做什麼 | 時間 | 耗材／加熱 | 會改的設定 |
|---|---|---|---|---|
| **綜合測試** | 先跑緩衝量測試，再用新的停駐量跑壓力測試，最後給一份總結 | 約 4～8 分鐘 | 約 30cm，會加熱 | 停駐量、壓力級別、待機夾持電流；「空閒時放鬆馬達」若開著會關掉 |
| **緩衝量測試** | 把活動件推到底量行程，設定停駐量（7.3） | 約 20 秒 | 不花耗材、不加熱 | 停駐量 |
| **壓力測試** | 找出推得動、夾得住的最低電流，推料加 1 級、夾持加 2 格餘裕（7.2） | 約 4～8 分鐘 | 約 30cm，會加熱 | 壓力級別、待機夾持電流 |

**第一次安裝**：把耗材送到 K1 擠出機（K1 的噴頭感測器要有料），然後按「綜合測試」。

**開始前的檢查**（三個都一樣，不符合就不會開始，網頁會寫原因）：馬達有 24V、喂竹器有料、喂竹器在 READY 或 STAGED、連得到 K1、K1 沒在列印、K1 噴頭感測器有料。

**中止**：再按一次同一個按鈕、按喂竹器任一鍵、或按網頁的「停止」。

**結果**：網頁會顯示通過或失敗、量到的數值，以及失敗時該檢查什麼，設定會自動存起來。常見的失敗原因：

| 網頁顯示 | 意思 |
|---|---|
| 送了 30mm 活動件都沒被撐開 | 耗材沒被 K1 擠出機夾住，或管子沒接好 |
| 找不到行程終點 | 梳齒感測器沒有訊號 |
| 兩次量測差太多 | 管子在晃或卡住，固定好再測 |
| 行程太短 | 鐵氟龍管太短或彎得太急 |
| 目前的壓力級別推不到新的停駐位置 | 只跑了緩衝量測試時會出現：量測本身有效，接著跑壓力測試即可 |
| 所有壓力級別都推不動活動件 | 路徑卡住 |
| 待機電流擋不住印表機的拉力 | 齒輪沒咬緊耗材 |

> 「空閒時放鬆馬達」開著時緩衝不會動作（見 7.1）。v0.8.1 起預設是關的；如果曾經手動打開，綜合測試會把它關掉並在結果裡註明，只跑另外兩個測試時請自己到設定裡關掉。

### 7.1 壓力級別

壓力級別就是馬達電流，同時決定兩件事：推料的力氣，以及**待機時齒輪夾住耗材的力氣**。

| 級別 | L1 | L2 | L3 | L4 | L5 | L6 | L7 | L8 | L9 | L10 |
|---|---|---|---|---|---|---|---|---|---|---|
| 電流 mA | 250 | 300 | 350 | 400 | 450 | 500 | 550 | 600 | 650 | 700 |

原廠韌體的運轉電流是 600mA（約 L8），待機時約一半。

本韌體把電流拆成三個用途，因為需求差很多：

| 用途 | 設定 | 為什麼分開 |
|---|---|---|
| 緩衝輔助進料 | 壓力級別 | 一次只推 10mm，但整場列印上千次 |
| 待機夾持 | 待機夾持電流 (mA) | 整場列印持續耗電，發熱主要來源 |
| 進退料／手動移動 | 進退料電流級別 | 一次幾百 mm，要克服整條路徑的摩擦；一天只有幾次 |

前兩個由壓力測試量出來，第三個維持較高的預設值（L8）—— 壓力測試不會測到長距離進退料的需求，用測出來的低電流去退料會打滑。

**夾住的力氣為什麼重要**：如果待機時齒輪夾不住，印表機會直接從料捲把耗材拉過齒輪，緩衝完全不會動作，等於沒裝喂竹器。所以「**空閒時放鬆馬達」必須關閉**，緩衝才會運作。想在不用的時候省電，改用「省電待機」（9.6）：它只在 K1 確定拉不動料的時候才放開。

### 7.2 壓力測試（分成推料與夾料兩段）

「電流夠不夠」其實是兩件事，而且只有第二件會整場發熱，所以分開量、各自加餘裕（推料加 1 級、夾持加 2 格，見下面「餘裕」）：

| | 推料 | 夾料 |
|---|---|---|
| 測什麼 | 馬達推不推得動活動件到停駐位置 | 待機時齒輪擋不擋得住印表機的拉力 |
| 失敗會怎樣 | 輔助進料跟不上，最後卡料警報 | 印表機直接從料捲拉料，緩衝形同虛設 |
| 決定哪個設定 | **壓力級別** | **待機夾持電流 (mA)** |
| 整場發熱 | 否（只在輔助進料的 0.5 秒） | **是** |
| 需要耗材 | **不用** | 需要，每一步約 50～70mm |

按一次「壓力測試」兩段會依序跑完。**前提**：見 7.0 的開始前檢查（v0.8.1 起多檢查 K1 噴頭感測器要有料）。夾料段開始前噴頭會自動加熱到設定溫度，測完恢復原本的目標溫度。

**第一段：推料（不花耗材）**

```
每一級：
  1. 請 K1 夾住擠出機（把耗材的另一端錨定住）
  2. 喂竹器自己往回抽，把緩衝裡存的鬆弛量抽掉
  3. 放手，讓正常的輔助進料迴圈把緩衝補回停駐位置
  4. 補得回來、距離合理、活動件沒有中途卡住 → 通過
```

第 2 步只抽回停駐的那一段，上限是「停駐量 + 6mm」，一看到活動件回位就停，不會去拉 K1 擠出機裡的料。

**第二段：夾料（需要耗材）**

壓力級別固定在第一段的結果，待機夾持電流依這個階梯往上找：**60 → 90 → 120 → 150 → 180 → 200 → 250 → 300 → 350…mA**（每次加 50mA 直到 700），超過運轉電流的不測。

每一步（v0.8.3 起）：

```
  1. 喂竹器自己把緩衝抽空，再讓輔助進料迴圈補滿      ← 起點：剛補完料
  2. K1 擠出固定長度（約 2.5 輪輔助進料的量）
  3. K1 再一次擠 2mm，直到活動件回到原位        ← 終點：再補完一次料
  4. 比較「喂竹器送出」和「K1 用掉」
```

起點和終點都是「剛補完料」，所以夾得住的話兩者應該相等。通過條件：**相差不超過 3mm 或 5%（取大的）**。

- 送出**少於**用掉：印表機直接從料捲把料拉過齒輪，待機電流不夠。
- 送出**多於**用掉：活動件的彈簧把存料推回齒輪另一邊，待機電流也不夠。停駐量越大彈簧越緊，這種情況越容易發生。

> v0.8.2 以前只擠固定長度就比比例，但輔助進料是一次一整輪（停駐量 15mm 時約 19mm），擠 48mm 只會補 2 輪或 3 輪，比例只可能是約 77% 或 121%，是哪一個還要看活動件起點剛好在哪裡。那時量出的結果（包括 150mA／90mA 的下限）只能當參考。

**兩段都用同一套搜尋方式**：先粗掃（每兩步一次，夾料段就是階梯上每隔一格），找到第一個通過的之後往下補測一步確認真正的下限，再把它**重測一次**確認不是僥倖，最後加上餘裕自動儲存。

**餘裕**（v0.8.4 起）：

| | 餘裕 | 例子 |
|---|---|---|
| 推料（壓力級別） | **加 1 級** | 下限 L1 → 存 L2 |
| 夾料（待機夾持電流） | **加 2 格**（照上面的階梯） | 下限 60mA → 存 120mA；下限 150mA → 存 200mA；下限 200mA → 存 300mA |

夾料多給一格，是因為測試只量了約一分鐘的穩定慢速拉料，沒涵蓋整場列印的回抽、快速擠出和震動。加上去後如果超過運轉電流，就停在運轉電流。
v0.8.3 以前兩段都只加 1 步。

> 實例（2026-09-21，停駐量 15mm）：推料下限 L1 → L2；夾料 60mA 兩次都通過（送出比用掉多 1.6、1.8mm，容許 3mm）→ 加 2 格 = **120mA**。

> 這兩段測試都是原廠韌體沒有的。**原廠的 calibration 是量路徑長度**，不是測電流（見 7.4）。舊版本曾有「張緊」和「退料式自動校準」，那是設計錯誤 —— 活動件是儲存鬆弛量的彈簧臂，往回拉只會把它清空、不可能把它推出去，所以那個判斷永遠不會成立，只會一路拉到上限磨料。v0.5.0 已移除。

### 7.3 緩衝停駐量（overfeed）

**原理**：耗材兩頭都被夾住——這頭是喂竹器齒輪（待機夾持），那頭是 K1 擠出機。喂竹器多送進去的料沒地方去，會在管子裡被壓縮、頂著彎管外側，把管子繃緊，繃緊的管子就把活動件（管子接頭）往外拉開，拉開的那段空間正好裝下多送的料。所以：

- **活動件被撐開 = 緩衝裡有存料**，撐得越開存越多
- 印表機吃料時，先吃掉的是這段存料；存料變少，管子放鬆，**彈簧把活動件拉回原位**，同時把存料往印表機推
- **回到原位 = 存料用完**，碰到原位開關就輔助進料

印表機「拉」耗材不會把活動件拉走：耗材在管子和接頭裡是自由滑動的，活動件只感覺得到管子被撐開或放鬆。直接拉耗材反而會讓管子放鬆，活動件往原位走。

活動件回到原位時開始輔助進料，補到它離開原位後**再多送「緩衝停駐量」**才停。這個值決定緩衝平常停在行程的哪裡（總行程約 21mm）；每一輪輔助進料約「離開原位前的 2～3mm + 停駐量」。

停在原位附近（值太小）有兩個缺點：

- 存料太少，印表機很快吃完；活動件回到原位到喂竹器補上來之間，印表機是直接拉著夾住的齒輪，這是它最費力的時候
- 輔助進料循環變得很頻繁

停得遠一點，彈簧反而會幫忙把料推向印表機，印表機只需要克服管內摩擦。實測 57 分鐘的列印，停駐量 2mm 時輔助進料 1117 次（平均每消耗 4.3mm 就回位一次）；提高停駐量可以等比例減少。

**保護**：多送的過程中如果梳齒感測器連續 3mm 沒有訊號，代表活動件已經推到底（或馬達推不動了），會立刻停止並記錄，不會繼續推到耗材彎折。所以這個值調大不會磨料；但停在外側端點時沒有空間吸收印表機的回抽，正式使用要留一點距離。

**量測行程**（v0.8.1）：每次輔助進料結束，網頁 API `/api/status` 的 `topup` 欄位會記下這一輪的量測值：

| 欄位 | 意義 |
|---|---|
| `home_mm` | 活動件離開原位前送了多少 |
| `over_mm` | 離開原位後實際多送多少（正常等於停駐量；推到底時會提早停） |
| `last_edge_mm` | 多送到第幾 mm 時梳齒最後一次有訊號 = 活動件實際停下的位置 |
| `edges` | 這一輪梳齒感測器的訊號次數 |
| `stalled` | 1 = 這一輪是推到底才停的 |

另外 `comb_edges` 是從上一次輔助進料開始到現在的梳齒訊號次數，`buf_full` 是韌體判定的「有存料」。推到底時記錄會寫 `buffer: carriage stopped moving X mm into the overfeed (last comb edge at Y mm, left home after Z mm, N edges)`，Y 就是這個停駐量能用的最大值。

**緩衝量測試**（v0.8.1）：

1. 請 K1 夾住擠出機，喂竹器往回抽，把存料抽掉，讓活動件回到原位（上限 30mm，一回位就停，不會去拉 K1 擠出機裡的料）。
2. 用進退料電流以 10mm/s 推料：先記下活動件離開原位前送了多少，再一直推到梳齒感測器連續 3mm 沒有訊號，也就是推到底。
3. 重複一次。兩次差超過 3mm 就判定不可靠。
4. 取比較短的那次當行程，**停駐量 = 行程 − 5mm**（無條件捨去，最少 3、最多 25），外側那 5mm 留給印表機的回抽（切片回抽約 1mm，PAUSE 3mm）。
5. 再把存料抽掉，讓一般的輔助進料迴圈用目前的壓力級別停到新位置。推不到就提示你跑壓力測試。

用進退料電流推，是因為要量的是機構的行程；目前的壓力級別推不推得到，交給壓力測試判斷。

### 7.4 路徑長度校準（自動，對應原廠的 calibration）

「鎖定進退料距離」關閉時，不需要按任何校準按鈕。當你**在 STAGED 狀態按上鍵送料**，而且送到一半 K1 的噴頭感測器從「無料」變成「有料」時，喂竹器就知道齒輪到噴頭感測器的實際距離，會自動把**距離進料**改成「實測值 + 路徑校準餘裕」並儲存（餘裕預設 20mm，可在設定裡改）。記錄會寫：

```
load: K1 toolhead sensor triggered after 468 mm, feeding 10 mm more
path calibrated: gear -> K1 toolhead sensor is 468 mm, load length now 488 mm (+20 margin)
```

前提是「送料到擠出機自動停」有開、而且開始送料時噴頭感測器是無料狀態（記錄會寫明武裝成功或失敗的原因）。

距離確認後可在網頁勾選**「鎖定進退料距離」**。鎖定後有三個效果：

1. 進料碰到 K1 感測器時仍會停止，但不再覆寫「距離進料」。
2. 完整退料不再學習、覆寫退料基準，退料卡住也不會污染下一次距離。
3. 上料及完整退料分別直接使用網頁設定的「距離進料」和「距離退料」。手動修改這兩個數字仍然有效。

## 7.5 印表機連線（Klipper / Moonraker）

喂竹器每 0.2 秒讀一次印表機的狀態：列印狀態、擠出機速度、溫度、一顆耗材感測器。資料超過 3 秒沒更新就當作斷線，以下功能自動停用，喂竹器照一般方式運作。唯一的例外是列印中鎖定：斷線前最後看到的是「列印中」就維持鎖定（見下表）。

| 設定 | 說明 |
|---|---|
| 印表機名稱 | 網頁、螢幕、記錄、推播裡提到印表機時用的名字，預設 `Printer`。只能用英數和一般符號（螢幕字型沒有中文），最多 12 字。這台請改成 `K1` |
| 位址／連接埠 | Moonraker 的位址。一般 Klipper 是 7125；K1 原廠 7125 和 4409 都可以 |
| API key | 平常留空。只有狀態列顯示「被拒絕（要 API key）」時才填，見 [`安裝說明.md`](安裝說明.md) 第 7 節。**填錯的 key 會讓原本連得上的也被拒絕**。網頁不會顯示已存的 key；留空儲存＝不變，「清除 API key」按鈕可以刪掉 |
| 耗材感測器 | 用來判斷「料已經到擠出機」的 Klipper 感測器，只支援開關式的 `filament_switch_sensor`（編碼器式的 `filament_motion_sensor` 開機後在料動之前都回報「無料」，會讓喂竹器以為擠出機是空的而不輔助進料，所以不列出）。**自動**：只有一顆就用它；有好幾顆時優先挑名字含 toolhead／extruder／nozzle／head／tool 的，都沒有就用設定檔裡最後一顆（K1 會挑到噴頭上的 `filament_sensor_2`）。選單會列出印表機實際有的感測器；選「不使用感測器」則只照距離送料 |

| 功能（網頁可個別開關） | 行為 |
|---|---|
| 列印中鎖定按鍵與網頁進退料 | K1 列印中，進退料、校準都停用；「停止」仍可用。K1 暫停時不鎖。列印中斷線時維持鎖定（螢幕「LOCKED: K1 offline」），K1 回報沒在列印才解開 |
| 卡料時暫停 K1 並推播 | STUCK! 時若 K1 正在列印就送 PAUSE，並推播「PBF: 卡料」（沒有輔助進料警報時是「PBF: 沒有輔助進料」） |
| 沒有輔助進料就警報（v0.11.0） | K1 列印中，印表機擠出了設定的量（預設 100mm），緩衝卻一次都沒空過、喂竹器一次都沒輔助進料 → STUCK!，並照上一項暫停＋推播。代表耗材不是從喂竹器來的：擠出機打滑或堵住、續料後新料沒被吃進去、或活動件感測器壞了。用印表機的 `print_stats.filament_used`（擠出量）判斷，不是用時間，所以加熱、調平、慢速層不會誤觸發。實測 K1 列印時每約 20mm 就輔助進料一次、最大間隔 27mm。設 0 關閉 |
| 噴頭沒加熱就不輔助進料（v0.11.1，固定開啟） | 印表機噴頭目標溫度是 0 時不輔助進料，正在輔助進料也會停下，螢幕顯示 `K1 heater off`（重新加熱後換成 `K1 printing: buffer on`，v0.11.7 起），記錄寫 `buffer: not topping up, K1 heater is off ...; carriage home／out`。這段期間印表機不會用料，活動件卻回到原位或離開原位時，會記一行 `buffer (held): carriage back home／left home`（每次最多 8 行）：活動件突然彈回原位，通常代表管子從擠出機卡扣鬆脫了。Klipper 本來就不能冷擠出，目標溫度 0 時印表機不會用到這些料。K1 的 END_PRINT 第一步就關加熱，之後才回抽 3mm、把噴頭移到右邊、降熱床，所以收尾時 Klipper 雖然還顯示「列印中」，喂竹器已經不動；也不會因為卡料把印完的列印暫停。連線中斷時沿用最後一次讀到的加熱狀態（v0.11.2 起）；開機後從沒連上過、或關掉印表機連線時照舊輔助進料 |
| 噴頭沒加熱時放鬆緩衝（v0.11.6，固定開啟） | 緩衝停駐時，活動件的彈簧就是靠拉緊管子撐住的，這股拉力一直掛在擠出機的卡扣上；省電待機放開齒輪也不會消失（料被夾輪夾著不會倒退）。所以噴頭目標溫度是 0、活動件撐開又靜止 2 秒後，喂竹器用 10mm/s 慢慢把停駐的那段退回來，**活動件一回到原位就停**，最多退「停駐量 + 6mm」：再退下去就是在拉擠出機裡的料了。螢幕顯示 `relaxing buffer XXmm`，完成後記錄寫 `buffer: relaxed X mm with the K1 heater off, carriage home`。收尾的回抽、噴頭移動又把活動件推出去時會再放鬆一次，每次關加熱最多 3 次。K1 重新加熱時就停止放鬆，活動件在原位就照常輔助進料補回（約一輪 17mm）。按鍵可以中止，中止後這次關加熱期間不再自動放鬆。退滿上限活動件還沒回原位時會停下並記 `relax pulled X mm and the carriage is still out`，代表活動件感測器可能有問題。開印時噴頭擦嘴巨集關加熱冷卻、或暫停時關加熱，也會放鬆一次再補回，不影響列印 |
| 進料到擠出機自動停 | 距離進料時，上面選的耗材感測器一偵測到料，就再送「感測器偵測到料後再送」的距離（預設 10mm，最多 5000mm）然後停：超過 40mm 的部分用手動送料速度，最後 40mm 慢速。原本設定的距離變成上限。感測器離擠出機比較遠（例如裝在料架旁）就把這個距離設成那段管長 |
| K1 回抽時同步倒轉 | K1 沒在列印時，擠出機回抽速度超過 3mm/s，喂竹器就同速倒轉（FOLLOW），K1 停下就跟著停 |
| G-code 指定雙向同步 | K1 沒在列印時，`M117 PBF:FOLLOW` 有效期間會同步正向進料與反向退料；長回抽也不會切成 FREE。大小寫皆可 |
| 耗材用完時推播 | 料尾離開喂竹器（RUNOUT）時推播「PBF: 耗材用完」 |
| K1 退料時放開齒輪 | 退料 G-code 送出 `M117 PBF:FREE` 時，馬達斷電讓齒輪空轉（FREE），見 9.5 |

- 推播用 Mobileraker Companion 的格式（`M117 $MR$:標題|內容`），K1 上要裝 Companion 才收得到。網頁有「測試推播」按鈕。
- 進料開始時如果噴頭感測器已經有料（料本來就在擠出機），就不會用它判斷，只照距離送。
- **「進料到擠出機自動停」目前是關閉的**（2026-09-20 依使用習慣關掉，改成手動插入）。關閉時距離進料只照設定的距離送，要送到擠出機請用「按住進料」自己控制。隨時可以在網頁重新開啟。

## 8. 警報與錯誤

| 畫面 | 原因 | 處理 |
|---|---|---|
| STUCK!：fed XXmm, buffer still empty（v0.8.0 以前寫 buffer still pulled） | 輔助進料超過卡料判定長度（預設 80mm），活動件還在原位、沒被撐開。多半是料尾卡在線盤，或齒輪打滑。預載完 3 分鐘內開始的輔助進料，上限放寬成卡料判定長度 + 路徑長度（手工續料，見第 9 節） | 檢查線盤和路徑，按任一鍵解除 |
| 壓力測試：no level worked | 連 L10 都沒通過 | 檢查管路是否過長、硬彎、卡住，或料捲阻力太大 |
| 壓力測試：heat the nozzle first | 噴頭沒熱，Klipper 不允許擠出 | 先把噴頭加熱到耗材的溫度 |
| ERROR：tip stuck: XXXmm pulled, still in the gear | 退到無料時退到上限（實測退料長度 + 20mm），料尾還卡在齒輪沒出來。多半是尖端成形的凸起卡住，或進退料電流不夠；也可能是這次需要退的長度比上次量到的多 20mm 以上 | 手動拉一下耗材幫它出來，或按任一鍵解除後再雙點下鍵一次；如果常發生，調高進退料電流級別 |
| ERROR：fed XXXmm, K1 never saw the filament | 上料送完整段距離，K1 的噴頭感測器始終沒反應。耗材可能歪掉、卡在半路，或沒進到感測器 | 手動檢查路徑，排除後重新上料。只有「整段上料」才會報這個，距離進料的點動不會 |
| NO POWER | 沒有 24V | 接上變壓器；恢復供電後會自動重新設定驅動晶片 |
| RUNOUT | 料用完，料尾離開齒輪 | 正常狀態，交給 K1 的斷料流程；插入新料會自動咬料 |

蜂鳴器開著時，警報會重複響，按任一鍵停止。

## 9. 典型流程

**上新料（對應你的第 1～4 步）**
1. 從入料口插入耗材 → 自動咬料、預載 100mm → STAGED。
2. 上鍵單點 → 距離進料送到 K1 → READY。第一次這樣做時會自動校準路徑長度（7.4）。
3. Mobileraker 按「進料」，K1 吃料時喂竹器會自動輔助進料。
4. 開始列印，列印中自動輔助進料。

**斷料（第 6 步）**
料尾通過入料口時只記錄、不動作；料尾離開齒輪後 → RUNOUT，馬達放鬆，交給 K1 的斷料流程。插入新料會自動咬料、預載，回到第 2 步。

**手工續料（列印中接新料）**
1. 料用完、料尾離開齒輪 → RUNOUT。
2. 列印繼續時，把新料插進入料口 → 自動咬料、預載 → 因為 K1 在列印，會自動回到 READY。
3. 喂竹器把新料一路推下管子，直到頂到舊料尾巴，撐開活動件，接著照常輔助進料（新料跟著舊料尾巴走）。
4. **接頭快到擠出機時持續施壓**（v0.11.0）：舊料尾巴離開喂竹器齒輪後，印表機再擠出約「路徑長度」，接頭就到擠出機齒輪。
   從預計到達前 100mm 開始，喂竹器每 1.5 秒把活動件推到行程底端，讓新料一直被壓向擠出機齒輪，直到擠出機把它吃進去。
   接頭過了擠出機 100mm、而且之後印表機又拉空緩衝 2 次，才算完成（記錄 `refill: done`）。
   一直沒被吃進去的話，推滿 30mm 就停止加推、保持壓力，並由「沒有輔助進料警報」暫停列印。網頁狀態列會顯示「續料：推新料進擠出機中」。

這段路可能有整條管子那麼長，活動件一直在原位，正常情況會被當成卡料。所以**預載完成後 3 分鐘內開始的輔助進料**，
卡料判定放寬成「卡料判定長度 + 路徑長度」（路徑長度＝距離進料，有開進料到擠出機自動停的話再加「感測器偵測到料後再送」）。
仍然有上限，真的卡住時不會一直送。記錄會寫 `refill: ... allowed`。3 分鐘後恢復一般判定。

要在 K1 的斷料感測器觸發之前接上。觸發之後 K1 會暫停並退料，喂竹器停在 STAGED，這時用上鍵單點進料就好（這種情況不會持續施壓，也不需要）。
施壓時機是用「路徑長度」估算的（第 10 節的距離進料，加上「感測器偵測到料後再送」），距離進料設得準，時機就準。

**手工續料的注意事項**

1. **看到 RUNOUT（或收到「PBF: 耗材用完」推播）就盡快插新料。** 舊料尾巴一路往印表機走，接得太晚，
   K1 的斷料感測器會先觸發、暫停列印，就變成一般的換料。
2. **新料前端要剪平、拉直**，不要有彎鉤或壓扁。前端要頂住舊料尾巴，之後還要被擠出機咬進去。
3. 插新料時推到喂竹器咬住（螢幕 IN2 方框變實心）就放手。之後不要拉它，也不用一直扶著。
4. **「距離進料」要設準。** 太短，施壓會開始得太晚，接頭已經到擠出機了才開始壓；
   太長，只是提早開始壓，沒有壞處。
5. 施壓期間喂竹器大約每 1.5 秒會「喀」一聲（馬達把活動件推到底），這是正常的。
6. 接頭經過擠出機那一小段，列印可能會稍微出料不足（接縫、擠出機換咬新料），印完檢查那幾層。
7. 擠出機一直沒把新料吃進去的話，K1 再擠出約 100mm 會被「沒有輔助進料」警報暫停（見下面）。
   這時把新料往擠出機推一下讓它咬住，**先在喂竹器按任一鍵解除警報，再到 K1 繼續列印**。
8. K1 已經暫停時才接新料（例如斷料感測器已經觸發）：不會自動施壓。用上鍵單點把料送到擠出機，
   確認擠出機有吃料後再繼續列印。

**卡料（第 5 步）**
輔助進料超過 80mm 活動件還在原位（沒被撐開）→ STUCK! 並停止馬達；K1 列印中會自動 PAUSE，並推播到手機。
預載完 3 分鐘內例外，見上面的手工續料。

**沒有輔助進料（v0.11.0）**
K1 列印中擠出了 100mm，緩衝一次都沒空過 → STUCK!（`no feed: K1 used 100mm`），自動 PAUSE 並推播「PBF: 沒有輔助進料」。
檢查擠出機有沒有吃料、噴頭有沒有堵、續料的新料有沒有被夾住，排除後按任一鍵解除，再到印表機繼續列印。

**沒有輔助進料警報的注意事項**

1. **一定要先在喂竹器按任一鍵解除警報，再到 K1 繼續列印。** 警報時喂竹器的馬達是放開的，
   沒解除就繼續印，K1 會直接從料捲拉料，緩衝不會作用，這個警報也不會再觸發。
2. 門檻 100mm 是在 K1 上實測的：列印時每擠出約 20mm 就輔助進料一次，兩次最多相隔 27mm。
   換了印表機或列印方式，如果常常誤報，就把門檻調高（例如 150～200）；設 0 關閉。
3. 前提是緩衝正常運作：「空閒時放鬆馬達」要關，齒輪要夾住耗材。刻意不經過緩衝列印時，請把門檻設 0。
4. 只在 K1「列印中」判斷。暫停、換料、手動擠料都不算；每次輔助進料就重新計算。
5. 需要跟 K1 保持連線。斷線期間不判斷，重新連上後從頭算。
6. 暫停和推播跟著「卡料時暫停 K1 並推播」這個開關。關掉的話喂竹器只會停在 STUCK!，不會暫停 K1。

**退料（第 7 步）**
1. 在 Mobileraker 執行你的退料 G-code。K1 回抽時喂竹器會同步倒轉（FOLLOW）。
2. 累計跟隨超過 20mm 時，喂竹器判定這是退料而不是列印回抽，**自動進入 STAGED 並暫停緩衝**（嗶一聲）。這一步很重要：不暫停的話，回抽剛把緩衝抽空，輔助進料迴圈就會立刻把料推回擠出機，跟退料打架。
3. 下鍵雙點 → 退到無料 → UNLOADED。也可以單點，退回設定的距離。

另外，只要 K1 回報擠出機裡已經沒有料（噴頭感測器無料、且沒在列印），喂竹器就不會輔助進料 —— 那時管子另一端是空的，推多少都撐不開活動件，只會一路推到卡料警報。畫面會顯示 `K1 extruder empty`。

**列印中自動恢復緩衝**
如果 K1 開始列印時喂竹器停在 STAGED（例如剛換完管子忘了切回去），它會自動切到 READY 並開啟緩衝 —— 否則整場列印 K1 都會直接從料捲拉料。

**換鐵氟龍管**
READY 時上鍵雙點 → STAGED（緩衝暫停），拉動管子不會觸發輔助進料。換好後上鍵單點送料，或用按住進料送到位。

## 9.5 退料時放開齒輪（K1 退料交握）

退料 G-code 裡的尖端成形會把耗材來回抽送好幾次（原廠序列是 4 組 ±5mm）。即使 FOLLOW 已支援雙向，
它仍靠 0.2 秒一次的輪詢反應，追不上這種快速短動作，容易在 G-code 已換向後才跟上。
**直接放開齒輪讓它空轉**，由印表機自己拉，乾淨得多。

### 只要改 Mobileraker 的退料 G-code

`M117` 會寫進 Klipper 的 `display_status.message`，這是標準物件，喂竹器輪詢時順便讀。
**印表機的 `printer.cfg` 完全不用改。**

```gcode
M117 PBF:FREE     ; 放開齒輪
G4 P400           ; 等兩個輪詢週期讓喂竹器反應
  ...（尖端成形、回抽）...
M400              ; 等動作真的做完
M117              ; 清掉訊息 → 夾回來
```

判斷方式是在訊息裡找 `PBF:FREE` 或 `PBF:FOLLOW`（大小寫皆可）；其他任何內容（包含空訊息）都當成一般待命。
完整的退料 G-code：K1 版在 [`tip-forming.md`](tip-forming.md)，其他 Klipper 印表機用通用版 [`tip-forming-generic.md`](tip-forming-generic.md)。兩份都是示範 `M117` 的用法，尖端成形動作可以換成你自己的。

FREE 後如果還要回抽，先切成 FOLLOW，讓喂竹器主動同步收料。目前的退料 G-code 就是這樣：
成形做完切 FOLLOW 收最後 60mm。要退幾百 mm 也是同樣寫法，把距離加大：

```gcode
M400
M117 PBF:FOLLOW   ; 從 FREE 改成主動同步倒轉
G4 P400           ; 等兩個輪詢週期
G1 E-250 F1800    ; 範例：額外長抽，距離／速度依你的機器修改
M400
M117              ; 全部完成後清除交握訊號
```

`PBF:FOLLOW` 是明確指令，因此不受「超過 25mm 自動改成 FREE」影響。為避免忘記清除訊號後在正式列印中持續送料，K1 回報「列印中」時不執行 FOLLOW。

上料的 `E200` 可以這樣雙向同步：

```gcode
M83
M117 PBF:FOLLOW
G4 P400
G1 E200 F300.0
M400
M117
```

`G4 P400` 讓喂竹器有兩個輪詢週期接收訊號；最後必須先 `M400` 等進料完成，再用 `M117` 清除訊號。

### 備援：沒有訊號時靠回抽長度判斷

不是每次退料都經過 Mobileraker —— 用 K1 觸控螢幕退料跑的是 `QUIT_MATERIAL`，沒有 `M117`。
所以還有第二條路：**跟隨回抽累計超過設定長度（預設 25mm）就改成放開齒輪**，
停止回抽 3 秒後夾回來。中途如果出現 `M117` 訊號，就交給訊號管（它知道確切的結束時間）。

這台機器的 `PAUSE` 只退 3mm，一般列印回抽更小，都不會誤觸。

### 喂竹器怎麼反應

- 看到 `PBF:FREE` → 進入 **FREE**，馬達斷電、嗶一聲，齒輪空轉。
- 看到 `PBF:FOLLOW` → K1 正向 E 動作時同速進料、負向 E 動作時同速退料；長回抽不會改成 FREE。
- 訊息清掉／改掉、逾時、按任一鍵、K1 開始列印 → 夾回來。
- 夾回來時如果 K1 回報噴頭已經沒料，就停在 **STAGED** 並**持續夾住**到下一次狀態改變，
  接著單按一下退料鍵就能把料拉回料盒。

### 安全機制

| 機制 | 行為 |
|---|---|
| 逾時（預設 60 秒） | 時間到自動夾回，而且在訊息變掉之前不會再放開 |
| 按任一鍵 | 立刻夾回，同樣鎖住不再自動放開 |
| K1 開始列印 | 立刻夾回 |
| 失去 K1 連線 | 立刻夾回（資料過期一律當成要夾住） |
| FREE 觸發後 60 秒 | 即使 FREE 提早結束、活動件已回原位，也禁止自動輔助進料；仍允許 FOLLOW。K1 一進入正式列印就立即取消此保護並恢復輔助進料 |
| 開機時訊息已經是 `PBF:FREE` | **不動作**，要等訊息清掉一次才算數 |
| 回抽判定的結束 | 停止回抽 3 秒（尖端成形擺動中的空檔都 < 1 秒，不會被誤判） |

後兩項是因為 **`M117` 的訊息會一直留著**，不會自己消失。退料 G-code 被取消的話
`PBF:FREE` 會留在畫面上，所以逾時夾回來之後要鎖住，開機看到既有訊息也要忽略。
夾不住的後果是 K1 直接從料捲把料拉過齒輪，緩衝完全不動作。

### 重要限制

**放開齒輪只適用於「印表機只把料退到離開自己的擠出機」的退料**（約 100mm）。
如果退料 G-code 有幾百 mm 的長抽，那段一定要由馬達主動倒轉（FOLLOW），
否則退回來的料在入料端沒有東西收，會塞成一團。

### 備用管道（選配）

印表機上如果有 `[gcode_macro PBF]`（`variable_mode: 0`），也可以改用
`SET_GCODE_VARIABLE MACRO=PBF VARIABLE=mode VALUE=1/2/0`，其中 1 = FREE、2 = FOLLOW、0 = 清除。
兩種管道都支援。**預設用 `M117` 就好，不需要加這個。**

### 手動測試

網頁「操作」區的**放開齒輪／夾住齒輪**按鈕，或序列埠 `free` / `grip`。手動放開一樣吃逾時。

## 9.6 省電待機（K1 閒置時放開齒輪）

READY 時齒輪要一直用「待機夾持電流」夾住耗材，緩衝才會運作（7.1），所以馬達整天都在耗電發熱。其實只有 K1 **拉得動料**的時候才需要夾。

**判斷依據**：Klipper 不准冷噴頭擠出，所以任何會動到耗材的事 —— 列印、Mobileraker 進退料、K1 螢幕上的進退料 —— 都一定要**先加熱噴頭**。反過來說，K1 沒在列印、沒在加熱、噴頭又冷到不能擠出時，它就拉不動料，齒輪可以放開；一開始加熱就夾回來，離第一次擠出還有好幾分鐘。

**進入**：READY 狀態下，以下條件**連續維持**設定的分鐘數（預設 5 分鐘）：

| 條件 | 看什麼 |
|---|---|
| K1 沒在列印、也沒暫停 | `print_stats` |
| 噴頭沒在加熱 | 目標溫度 = 0 |
| 噴頭冷到不能擠出 | Klipper 的 `can_extrude`（K1 約 170°C 以下） |
| 喂竹器沒在動 | 沒有輔助進料、手動移動、測試；期間也沒有按鍵或網頁操作 |

**喚醒**（夾回齒輪、回到 READY），任一個成立就立刻喚醒：

- K1 開始列印或暫停
- K1 開始加熱噴頭，或噴頭還熱到可以擠出
- K1 的擠出機在動
- 按喂竹器任一鍵（只喚醒，不做其他動作），或在網頁上做任何操作（喚醒後照常執行）
- 關掉「省電待機」或「K1 連線」

放開齒輪**不會**讓存料退回去：料被夾輪夾著，實測待機 20 分鐘後活動件還是撐開的。所以 v0.11.6 起，噴頭一關加熱就先把緩衝放鬆（第 7 節功能表「噴頭沒加熱時放鬆緩衝」），進入省電待機時緩衝通常已經是空的。喚醒後 K1 一加熱、緩衝是空的，就會輔助進料一次，把緩衝補回停駐位置。省電待機期間活動件如果回到原位或離開原位，也會記一行 `buffer (held): ... (K1 standby, standby)`，方便找出管子脫出的時間點。

**K1 關機或斷線時**：喂竹器沿用最後一次讀到的 K1 狀態。K1 關機前如果是閒置、冷的，就照樣進入或維持省電待機；K1 重新開機、連上以後照上面的條件判斷。喂竹器開機後一直連不到 K1，也當作 K1 關機處理。

> 唯一的風險：喂竹器在省電待機時剛好斷線，K1 又在這段期間開始列印。這時齒輪是放開的，K1 會直接從料捲拉料（跟沒裝喂竹器一樣，還是印得出來），等連線恢復、看到 K1 在列印才夾回來。

**設定裡關掉「K1 連線」時不會進入省電待機**：那樣喂竹器永遠不知道什麼時候該喚醒。

網頁狀態區會顯示倒數（例如「4:32 後省電待機」）；進入後狀態顯示「省電待機（齒輪放開）」。記錄會寫：

```
standby: K1 idle for 5 min (not printing, not heating, too cold to extrude)
READY -> STANDBY: K1 idle: gear released
STANDBY -> READY: woke: K1 heating
```

和「空閒時放鬆馬達」的差別：那個設定是 READY 一閒下來就放開，K1 列印時緩衝也會失效；省電待機只在 K1 確定拉不動料的時候放開。

## 10.5 統計（存在 flash）

網頁的「統計」區塊會顯示累計的送出／退回長度、輔助進料次數、卡料警報、退料卡住次數、UART 干擾次數和通電時數。

這份資料存在 flash，但刻意設計得很保守：

- 固定大小的區塊，永遠不會增長
- 計數放在記憶體，**最多每 10 分鐘**寫一次 flash（列印結束時會多寫一次）。NVS 的抹寫壽命有限，而一次列印就有上千次輔助進料，逐次寫入會很快寫壞
- 每次讀取都驗證 magic、版本和 checksum，不吻合就直接歸零重來，絕不拿可疑資料去顯示
- 更新韌體後自動歸零（欄位定義可能已經改了）
- 寫不進去就只計算本次開機，並在網頁上標示 —— **統計功能失效不會影響送料**

「清除統計」按鈕（紅色，按下會先確認）隨時可以把它歸零。

- 噴頭沒加熱就不輔助進料（v0.11.1）2026-09-27 燒錄後確認：K1 目標溫度 0、活動件在原位時不會輔助進料。同一天 02:03 實際收尾：關加熱時正在開始的輔助進料有停下，但印完後 K1 連線中斷，v0.11.1 把斷線當成「不知道」又推了 82mm，v0.11.2 已修正（斷線沿用最後讀到的狀態），還沒遇到實際斷線驗證。v0.11.2 燒錄後確認：開機連上 K1、加熱關著時不輔助進料，記錄同時寫入的兩行都有留下。重新加熱後恢復輔助進料已確認（2026-10-11 v0.11.5 開始列印、加熱後正常輔助進料）。它避免的是管子脫出**之後**的硬推和暫停；2026-09-26 那次管子本身為什麼脫出還沒確認（推測是緩衝停得很滿時，收尾的回抽加上噴頭移到最右邊，活動件沒有行程可讓，拉力落在擠出機卡扣上）。v0.11.6 起關加熱就會放鬆緩衝，收尾和閒置時卡扣不再受緩衝的拉力；收尾第一步關加熱後馬上就回抽、移動噴頭，放鬆的動作跟這些幾乎同時發生，所以收尾那幾秒的拉力只能減輕，擋不完。
- 列印中的輔助進料記錄（v0.11.0 起）每分鐘最多一行摘要。記錄只存最後 80 行，以前每次輔助進料一行，幾分鐘就把其他事件洗掉了。
- 緩衝量測試和綜合測試 2026-09-21 在實機跑完：活動件行程 20.4mm、停駐 15mm、運轉電流 L2、夾持 90mA。v0.11.3 改過測試結束時的保護，之後沒有在實機重跑。
